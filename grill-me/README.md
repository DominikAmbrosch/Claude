# grill-me

Vendored copy of the [`grill-me`](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md)
skill from [mattpocock/skills](https://github.com/mattpocock/skills) (translated to German).

Interviews you relentlessly about every aspect of a plan, decision, or idea until a shared
understanding is reached — asking one question at a time, with a recommended answer for each,
and looking up anything discoverable from the environment itself instead of asking.

## Install

```bash
bash grill-me/install.sh
```

This copies the skill to `~/.claude/skills/grill-me/`. Restart Claude Code afterwards so it's
picked up, then say "grill mich" or invoke `/grill-me` to stresstest a plan.
